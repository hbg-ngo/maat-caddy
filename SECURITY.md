# Security policy

## Supported versions

Only the latest release (`ghcr.io/hbg-ngo/maat-caddy:latest`) receives security fixes.

## Reporting a vulnerability

Please do not open a public issue. Report it privately through
[GitHub private vulnerability reporting](https://github.com/hbg-ngo/maat-caddy/security/advisories/new).
We aim to respond within a week.

See [docs/security.md](docs/security.md) for the security design.
